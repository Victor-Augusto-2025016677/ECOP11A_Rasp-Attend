Iniciar bash

REPO_ROOT=$(pwd)

Imprimir "inicio instalação e configuração da solução" (ou algo assim, mais formal)

Primeiro, será oferecido uma série de escolhas ao usuário, nessa ordem:

Oferece o serviço de leds automáticos para os status dos serviços
Fala que mais informações estão disponíveis na pasta /docs

A resposta tem que ser sim ou não, escolha a melhor maneira para isso.

A 2°, oferece o uso de Ventoinha para refrigeração

novamente, sim ou não (ou y & N, a melhor maneira que você achar)

e diz que mais informações estão disponíveis em /docs

Com estas escolhas feitas, iniciamos a instalação.

Se alguma das 2 for sim, segue para os seguintes comandos

sudo chmod +x REPO_ROOT/pinctrl_lib/pinctrl_install.sh (acho que a maneira está errada, corrige se necessário)
e então: sudo ./pinctrl_lib/pinctrl_install.sh

Caso, o serviço de leds for aceitado, faz os seguintes comandos:

echo -e "\n>>> [1/4] Iniciando a Instalação do serviço de leds..."

CONFIG_FONTE1="scripts/personalizadas/led_on/pinctrl-monitor.sh"
CONFIG_DESTINO1="/usr/local/bin/pinctrl-monitor.sh"

echo -e "\n>>> [2/4] Copiando script de leds"

if [ ! -f "$CONFIG_FONTE1" ]; then
    echo "    ERRO: Arquivo '$CONFIG_FONTE1' não encontrado! Certifique-se de executar da pasta do repositório."
    exit 3
fi

sudo cp "$CONFIG_FONTE1" "$CONFIG_DESTINO1"
echo ">>> [2/4] Script de leds copiado"





echo -e "\n>>> [3/4] Copiando .service do serviço de leds..."

CONFIG_FONTE2="scripts/personalizadas/led_on/pinctrl-monitor.service"
CONFIG_DESTINO2="/etc/systemd/system/pinctrl-monitor.service"

if [ ! -f "$CONFIG_FONTE2" ]; then
    echo "    ERRO: Arquivo '$CONFIG_FONTE2' não encontrado! Certifique-se de executar da pasta do repositório."
    exit 3
fi

sudo cp "$CONFIG_FONTE2" "$CONFIG_DESTINO2"
echo -e "\n>>> [3/4] .service de leds copiado"

sudo chmod +x /usr/local/bin/pinctrl-monitor.sh
echo ">>> [4/4] script definido como executável."

sudo systemctl daemon-reload
echo ">>> Recarregando systemd daemon..."

CONFIG_FONTE5="scripts/personalizadas/led_on/shutdown_pins.sh"
CONFIG_DESTINO5="/usr/local/bin/shutdown_pins.sh"
sudo cp "$CONFIG_FONTE5" "$CONFIG_DESTINO5"
sudo chmod +x /usr/local/bin/shutdown_pins.sh

sudo systemctl enable pinctrl-monitor
sudo systemctl start pinctrl-monitor
echo ">>> Serviço de leds habilitado e iniciado."


CONFIG_FONTE5="scripts/personalizadas/led_on/shutdown_pins.sh"
CONFIG_DESTINO5="/usr/local/bin/shutdown_pins.sh"
sudo cp "$CONFIG_FONTE5" "$CONFIG_DESTINO5"
sudo chmod +x /usr/local/bin/shutdown_pins.sh

CONFIG_FONTE6="scripts/personalizadas/led_on/rede-delay.sh"
CONFIG_DESTINO6="/usr/local/bin/rede-delay.sh"
sudo cp "$CONFIG_FONTE6" "$CONFIG_DESTINO6"

//esses ultimos 2, pode dar echo se quiser, dizendo o motivo.
obs: o motivo do "shutdown" é desligar os leds em momentos de reboot ou shutdown, e de um aviso que devido a configuração padrão do rasp, enquanto o sistema não estiver bootado, pode ter algum acendimento do led, e isso esta fora do controle, e é corrigido assim que o boot é realizado
obs2: o motivo do "rede-delay" novo, é que esse tem uma animação mostrando os leds, avisando que bootou e que ele finalizou e mais algumas outras animações. 
fim da instalção do serviço de leds
